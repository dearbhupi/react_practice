# Fieldnote Weather

A standalone React + Vite weather dashboard using Open-Meteo's public APIs for city search, current conditions, and hourly forecasts. No API key is needed for this demo.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Build with `npm run build`.

Weather model data is updated periodically and is not a live observation from a personal weather station. See [Open-Meteo's forecast API](https://open-meteo.com/en/docs) and [geocoding API](https://open-meteo.com/en/docs/geocoding-api) for service details and usage terms.
